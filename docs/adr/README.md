# Architecture decision records

Architecture decision records capture material decisions that are durable, cross-cutting, or costly
to reverse. Copy `0000-template.md`, assign the next four-digit number, and submit it with the
change it governs.

An ADR has one of these states: proposed, accepted, rejected, deprecated, or superseded. Accepted
ADRs are immutable except for spelling and link repairs. Replace a decision with a new ADR and mark
the old record superseded.
