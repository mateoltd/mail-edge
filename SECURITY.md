# Security policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use
[GitHub private vulnerability reporting](https://github.com/mateoltd/mail-edge/security/advisories/new)
and include affected versions or commits, impact, reproduction steps, and any known mitigations.

Maintainers will acknowledge a report within five business days, coordinate validation and
remediation privately, and credit reporters when requested and safe. Please do not disclose the
issue publicly until a coordinated release or an agreed disclosure date.

## Supported versions

Before the first public release, only the current `main` branch receives security fixes. After
releases begin, supported versions will be listed here; unsupported versions will not receive
backports.

## Scope

Reports about dependency compromise, build or release provenance, secret exposure, authorization
boundaries, unsafe input handling, or denial of service are welcome. Questions and ordinary defects
belong in the public issue tracker.
